# Caddy Proxy Tools 2.1.1

发布日期：2026-10-20

### 界面优化

- 将设置、项目健康检查、配置导入与导出中的原生下拉框替换为统一的自定义菜单，提供选中标记、悬停高亮和选项说明。
- 下拉菜单支持方向键选择、回车确认与 Escape 关闭，长列表可滚动，小窗口下自动调整展开方向，适配深浅主题。
- 数字输入统一样式并加入加减按钮，达到上下限时禁用对应按钮；代理参数仍可清空以继承上级设置。
- 统一多行输入框、复选框，以及日志详情和高级设置的折叠面板样式。
- 数字按钮修改可正确触发未保存提示；切换设置分类或收起高级配置后保留输入内容，保存时一并提交。

### 图标更新

- 重新设计应用图标：使用与界面一致的紫色渐变圆角底，将 C 字母与请求分流结构结合，简化细节以适配小尺寸显示。
- 同步更新 Windows ICO、macOS ICNS、各尺寸 PNG、侧栏标识和网页图标。
- Windows / Linux 托盘使用彩色图标，macOS 使用随系统菜单栏主题适配的单色模板。
- 保留可编辑的 SVG 源图，并提供统一生成各平台图标资源的命令。
