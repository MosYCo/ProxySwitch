# Moss ProxySwitch 0.2.1

发布日期：2026-10-22

### 应用更新与安装

- 修复应用更新弹窗底栏按钮被裁切的问题，更新说明支持标题、列表与代码排版，长内容统一在正文区域滚动。
- Windows EXE 覆盖安装和卸载会先关闭旧应用，再停止安装目录中的 Caddy 并等待退出，避免引擎文件仍被占用；其他目录下的 Caddy 保持运行。
- 应用内更新、停止和重启引擎会等待 Caddy 退出确认；停止失败时保留运行状态并中止后续安装，避免提前覆盖正在使用的文件。

### 构建与维护

- 升级前端构建工具 Vite 至 6.4.4，并保留官方组件源码校验与界面交互回归。
- 建立 `develop` 开发分支与 `master` 稳定发布流程，依赖维护更新按组提交；发布前校验版本标签对应的提交已进入稳定分支。
