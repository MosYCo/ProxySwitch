# Moss ProxySwitch 0.2.0

发布日期：2026-10-21

### 界面与交互

- 导航栏支持收起为图标栏、点击边缘和快捷键切换，并记住展开状态，收起后仍可直接打开项目。
- 加强当前环境的边框、背景与状态标签，明确区分正在转发、已选择待生效和未使用的环境。
- 侧栏、设置分类、环境筛选、日志类型、折叠详情、数字输入组合和通知使用官方组件，保留未保存参数与自动填充禁用偏好。
- 高级配置折叠或切换设置分类时保留输入内容，小窗口中可滚动访问表单与保存按钮。

### 项目与环境图标

- 创建和编辑项目、环境时可选择 24 个内置图标或 Emoji，支持粘贴自定义 Emoji 和恢复自动图标。
- 图标随配置保存、重新加载、导入导出与备份恢复；旧配置继续使用自动匹配图标。

### 组件维护与验证

- 基础组件统一为官方 shadcn/ui Radix Nova 源码，品牌主题与业务逻辑独立维护。
- 升级到 React 19 和 Tailwind CSS 4，需要支持现代 CSS 的 WebView；Windows 请保持 WebView2 更新，macOS / Linux 需要 Safari 16.4 同代及以后的 WebKit 能力。
- 提供组件差异查看、官方更新、来源校验命令及浏览器交互回归检查，避免直接修改基础组件导致后续升级冲突。
