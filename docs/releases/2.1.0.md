# Caddy Proxy Tools 2.1.0

发布日期：2026-10-20

### 新增

- 统一设置页：启动与退出、请求与日志、健康检查、代理默认值、Caddy 引擎、数据与备份。
- Windows 登录自启、启动隐藏到托盘，以及关闭窗口时隐藏或退出的选项。
- 按项目查看代理请求，展示请求发生时的环境、后端、方法、原始路径、状态码、来源和耗时；支持搜索、异常筛选与慢请求标记。
- 项目和环境可独立配置连接超时、响应头超时、Host、请求与响应 Header，并继承上级默认值。
- 自定义项目匹配路径和转发路径，共用端口时按实际匹配的项目记录请求。
- 健康检查可选择当前或全部环境，并配置间隔、超时、路径、预期状态码和回退规则。
- 请求日志采集开关、缓存数量、忽略路径、查询参数脱敏及磁盘保留期限。
- 项目配置导入预览、合并或替换、单项目或全部导出，以及自动备份和手动恢复。
- Caddy 意外退出后自动恢复及重试上限设置。
- 打包前校验版本与更新日志，发布目录同时提供安装包、更新说明和 SHA-256 校验文件。

### 优化

- 导航调整为项目总览、项目配置和运行日志；移除项目内重复的近期记录，提供「查看请求」入口。
- 软件事件与 Caddy 日志分开查看，收起例行记录，合并重复事件，保留原始日志详情。
- 项目可单独启停，停用后保留环境配置；Caddy 停止时也能编辑并保存配置。
- 表单提供复制、保存反馈和错误定位；设置草稿可跨分类保留，关闭前提示未保存的修改。
- 兼容旧配置，默认不自动清理已有磁盘日志。

### 修复

- 修复状态一直显示「同步连接中」的事件订阅问题，并支持失败重试。
- 修复本地 HTTP 代理产生 HTTP/2、HTTP/3 需要 TLS 的重复警告。
- 改进 Caddy 启动就绪检查、进程退出诊断和配置失败回滚，避免错误覆盖原配置。
- 禁用输入框不必要的自动填充。
- 修复小窗口下设置页保存按钮被遮挡的问题。

### 使用说明

- 更新后重新启动应用，或重载 Caddy 配置，使新的请求归属记录生效。
- 启动相关选项在下次启动时生效；开机自启和自动恢复默认关闭。
- 查询参数脱敏应用于新记录；旧磁盘日志不会重写。
- 导出与普通导入仅迁移项目及环境；恢复备份时可选择同时恢复应用设置。
