# 使用说明

## 配置与访问

- 项目名、同一项目下的环境名必须唯一。Caddy 停止时可编辑并保存配置，下次启动生效；正在运行时由 Caddy 确认后才会保存，保存失败会尝试恢复修改前的运行配置。
- 每个项目的完整入口显示在工作台。共用端口时，先为该端口所有启用项目设置「使用项目路径前缀」，例如 `http://localhost:8080/myapp/`。项目增删不会自动切换其他项目的入口形式。
- 新项目可选择转发时移除项目路径前缀。旧共享端口配置会保留前缀及原有转发方式。
- 「项目总览」展示所有项目的状态和入口，点击项目进入「项目配置」管理启停、监听端口和环境。项目页的「查看请求」会进入运行日志并自动筛选该项目。
- 侧栏顶部的收起按钮、侧栏边缘和 `Ctrl+B`（macOS 为 `⌘B`）可切换图标栏与完整导航。收起后仍可点击项目图标，悬停查看名称；应用会记住展开状态。
- 创建或编辑项目、环境时可选择内置图标或 Emoji，也可粘贴一个自定义 Emoji。点击「恢复自动图标」恢复默认展示；项目默认显示文件夹，环境按名称自动匹配开发、测试或生产图标。图标随项目配置保存、导入导出和备份。
- 当前环境以主色边框、侧边标记和实心标签突出显示。仅当项目启用且引擎运行时显示「正在使用 · 当前转发」；项目停用或引擎停止时显示「已选择 · 待生效」，其他环境显示「未使用」。
- 每个项目可在「项目配置」通过「启用此项目」单独启停，新建项目时也可关闭「创建后启用项目」。停用后保留环境配置和当前选择，移除该项目路由并暂停健康检查；独占端口会释放，共用端口上的其他项目继续运行。状态会保存，重启应用时仅启动已启用的项目。Caddy 引擎停止时也可保存启停设置，下次启动引擎时生效。
- 后端地址支持路径，例如 `https://api.example.com/api/v2`；请求路径会接在该路径后，查询参数会保留。后端地址本身不支持认证信息、查询参数和片段。
- 健康检查在 `/health` 不存在时回退检查后端入口，并遵循环境的 HTTPS 证书校验选项。刷新工作台会立即检查。
- Caddy 使用指定的管理地址，启动和停止仅管理本应用的子进程。管理地址停止服务时可保存，下次启动生效。
- 运行日志默认展示「请求记录」：项目、当时使用的环境和后端、方法、原始路径、状态码、耗时及请求来源。支持按项目、关键词和异常请求筛选，也可切换「软件事件」「Caddy 运行日志」。项目归属在请求转发时写入日志，历史记录不会随环境切换而重新归类；共享端口按实际匹配的项目记录。旧记录未包含项目标记时不会猜测归属。
- Caddy 访问日志包含请求路径、状态码、来源与耗时，并保留原始 JSON 结构。更新后重载配置或重启引擎即可启用；仅能采集由本应用启动的 Caddy 进程输出。两个日志来源默认各保留当前会话最近 500 条，可在设置中调整。查询参数按脱敏规则处理后再展示和落盘；清空面板不删除磁盘日志。
- 本地代理入口使用 HTTP/1.1，转发到 HTTPS 后端时仍使用对应环境的 TLS 配置。应用事件使用 Tauri 支持的名称同步；事件订阅失败时状态栏显示重试状态，悬停可查看原因。

## 应用设置

侧栏的「设置」包含六类选项：

| 分类 | 可配置内容 |
| --- | --- |
| 启动与退出 | Windows 登录自启、应用启动时启动 Caddy、启动隐藏到托盘、关闭窗口时隐藏或退出 |
| 请求与日志 | 请求记录开关、每来源缓存数量、日志保留天数、慢请求阈值、忽略路径、查询参数脱敏 |
| 健康检查 | 总开关、检查当前或全部环境、间隔、超时、检查路径、预期状态码、根路径回退 |
| 代理默认值 | 连接超时、响应头超时、Host、请求与响应 Header 的覆盖及删除 |
| Caddy 引擎 | 管理地址、引擎日志级别、意外退出后的自动恢复和重试上限 |
| 数据与备份 | 按项目或全部导出到下载目录、导入预览与合并/替换、自动备份数量、手动备份与恢复 |

- 代理参数按「全局 → 项目 → 环境」继承。同名 Header 不区分大小写，`名称: 值` 用于设置，`-名称` 用于删除。留空超时继承，响应头超时为 `0` 表示不限时，适合流式接口。
- 项目编辑中的高级规则支持自定义匹配前缀和转发前缀，例如 `/api/order/users` 替换 `/api/order` 为 `/v1` 后转发为 `/v1/users`，再拼接后端地址的基础路径。嵌套匹配前缀优先匹配更具体的路由，同一端口不能重复匹配前缀。
- 项目、环境均可覆盖健康检查开关、路径、超时、状态码及回退选项；全局总开关关闭或项目停用时暂停所有相关检查。检查时限覆盖回退尝试的总耗时，且使用继承后的请求 Header 和 Host。
- 忽略日志路径支持精确匹配及末尾 `/*` 的前缀匹配。敏感查询参数在消息、原始数据及磁盘日志中脱敏，既有磁盘文件不会重写。磁盘保留天数默认 `0`（不自动清理），选择正数后清理到期的按日保存日志。
- 默认在配置修改前备份，最多保留 10 份；导入仅迁移项目与环境，保留本机应用设置。恢复备份默认恢复项目，可选择同时恢复应用设置；运行中的配置校验失败会保留原有配置。
- 自动恢复仅处理托管进程的意外退出，手动停止和退出应用不会触发恢复；连续重试达到上限后停止，稳定运行一分钟后重置计数。开机自启默认关闭，其他启动行为与旧版本兼容。
